# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a documentation-only repository containing a structured learning plan for mastering Claude Code. The main content is in `mastering-claude-code-plan.md` — a 12-module curriculum covering Claude Code from foundations through advanced patterns (subagents, plugins, CI/CD, context engineering).

There is no build system, test suite, or runnable code. The repository is purely educational content written in Markdown.

## Key Context

- The learning plan targets developers working with NestJS projects (used as the example stack throughout)
- Modules progress from basics (installation, first session) through intermediate (CLAUDE.md authoring, slash commands, MCP) to advanced (subagents, plugins, headless CI/CD, orchestration patterns)
- The plan references Claude Code extension points in chronological order: MCP, Subagents, Hooks, Plugins, Skills, Agent Teams

## When Editing the Learning Plan

- Maintain the existing module/lesson numbering structure (Module X → Lesson X.Y)
- Each lesson follows a consistent format: topic bullets, key concepts in **bold**, and a **Hands-on** exercise at the end
- Keep content accurate to current Claude Code capabilities — verify feature names and slash commands against the latest documentation
